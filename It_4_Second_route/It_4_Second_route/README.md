 Задача 14. Второй по длине маршрут
Имя входного файла: input.in
Имя выходного файла: output.out
Ограничение по времени: 1 с
Ограничение по памяти: 256 МБ

Задано N городов c номерами от 1 до N и сеть из M дорог с односторонним движением между ними. Каждая дорога определяется тройкой (i, j, k) 
натуральных чисел, где i — номер города, в котором дорога начинается, j — номер города, в котором дорога заканчивается,
а k — её длина. Дороги друг с другом могут пересекаться только в конечных городах.

Все ориентированные маршруты между двумя указанными городами A и B можно упорядочить в список по неубыванию их длин. 
Необходимо найти один из маршрутов, который является вторым в этом упорядоченном списке (между городами A и B существует 
по крайней мере два ориентированных маршрута). Вывести его длину L и города, через которые он проходит 
(искомый маршрут по дугам может проходить несколько раз).

Формат входных данных
Первая строка содержит два целых числа N и M (1 ≤ N ≤ 10 000, 1 ≤ M ≤ 100 000).

Затем идут M строк файла по три числа в каждой: i, j, k.

Последняя строка содержит номера городов A и B.

Формат выходных данных
Первая строка должна содержать длину второго по длине маршрута между городами A и B.

Вторая строка — это номера городов, через которые проходит второй по длине маршрут.

В случае если вторых по длине маршрутов несколько, выдать в выходной файл информацию о любом из них.
